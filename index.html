A bar or a box

Drag an edge. Narrow it past half your screen and the ticker stacks itself into a corner box, logos and all. Drag it back and it spreads out again.

Or run it in a tab

Same bug, nothing to install. On a Chromebook or a laptop, press Pop out and it lifts into its own small window that stays on top of everything else — on ChromeOS that is the only way to get an overlay at all, since apps in the Linux container can't float above ChromeOS windows.

Keep it square. The pop-out is a few hundred pixels wide, which is exactly where the ticker folds into its box — that is the shape to leave it. Stretched wide it has to cram a full broadcast bar into a window with no room for one, and everything shrinks to fit.

On a phone there is no pop-out to press — mobile browsers don't offer one — so the box simply takes the whole screen instead.

Your fantasy league, live

Paste a Sleeper or public ESPN league link. Matchups as they move, the week's top performers across the whole league, standings, and your league's own scoring settings — in a sidebar that pins, scrolls itself and collapses.

It stays out of the way

Clicks pass straight through the empty space around it, and it never takes focus — so a fullscreen game stays fullscreen instead of dropping you to the desktop.

Before you download

The honest part

Only the Windows build has actually been used.
The macOS and Linux builds come off the same source and are published, but nobody has run them for a season. Scores should be fine; the overlay behaviour — floating over a fullscreen game, clicks passing through, the tray icon — is the part to watch.
The browser version floats, but it doesn't vanish.
Pop out gives you a genuine always-on-top window — as close as a browser is allowed to get. It still keeps a window frame, and clicks land on it instead of passing straight through, so it sits beside what you're watching rather than invisibly over it. Phones get no pop-out at all — mobile browsers don't expose one — so there it is a full-screen box rather than an overlay. If you can run the desktop build, run the desktop build.
Windows will warn you on first run.
The installer isn't code-signed. SmartScreen shows "Windows protected your PC" — More info, then Run anyway.
macOS will block it outright, and word it badly.
Unsigned apps get refused with "Bugline is damaged and can't be opened." It isn't damaged — that is what macOS says about anything it can't verify.
  1. Open the .dmg and drag Bugline to Applications.
  2. Run xattr -dr com.apple.quarantine /Applications/Bugline.app in Terminal.
  3. Open it normally.
That clears the download flag on this one app and nothing else. Signing it properly needs a paid Apple developer account; until then, auto-update doesn't work on macOS either — new versions mean a new download.
Linux needs an X11 session.
Wayland doesn't let an app place itself above other windows, which is the entire job here, so pick "on Xorg" at the login screen. Make the AppImage executable first; on Ubuntu 22.04 and later it may need --appimage-extract-and-run.
ESPN fantasy leagues have to be public.
League Settings → Make League Viewable to Public. A private league can only be read while signed in as a member, and Bugline won't ask for your account. Sleeper works as-is.
Scores come from ESPN's public endpoints.
No key, no account, nothing to sign up for. They're undocumented, so a change on their end can break a corner of it.
